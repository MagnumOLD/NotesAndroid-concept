# NotesAndroid Concept

Новая самостоятельная версия NotesAndroid. Проект развивается отдельно от `NotesAndroid` и `NotesAndroid-Build`.

## Визуальный эталон

`MagnumOLD/NotesAndroid-Build` (ветка `main`) — утверждённый источник актуального интерфейса NotesAndroid. При переносе компонентов сохраняются система направляющих, типографика, отступы, карточки, темы, подборки и согласованные взаимодействия.

## Продуктовая цель

Модульный органайзер с общей хронологической лентой и отдельными модулями: Заметки, Задачи, Таймеры, КБЖУ, Тренировки и Покупки. Полная спецификация находится в `docs/PRODUCT_PLAN.md`.

## Разработка

- Репозиторий: `MagnumOLD/NotesAndroid-concept`
- Основная ветка: `main`
- Уникальный applicationId: `com.magnumold.notes.concept`
- Минимальная версия Android: будет зафиксирована в Gradle-конфигурации.
- APK публикуется как артефакт GitHub Actions после успешной сборки.

Старые репозитории не изменяются.
